## Compact Mode

- Be concise and action-oriented.
- Do not repeat context.
- Inspect only files relevant to the task.
- Avoid unrelated investigation or refactoring.
- Run only relevant tests.
- Keep final responses under 10 lines.
- Report only changes, tests, risks, and commit.

## Execution Mode

- Continue autonomously until the requested task is fully complete.
- Do not stop for confirmation between related steps.
- Implement → test → review diff → commit.
- Only stop for a real blocker, destructive action, missing credential, or decision requiring user input.
- Do not perform unrelated work.
