# Codex Execution Rules

## Execution Mode

Operate in Silent Implementation Mode.

- Begin implementation immediately.
- Do not narrate your plan.
- Do not describe repository exploration.
- Do not summarize files being read.
- Do not provide progress updates.
- Only ask questions if blocked.
- Keep reasoning internal.

## Completion Format

When finished, provide only:

- Files modified
- Summary of changes
- Build/test result
- Remaining blockers (if any)

Do not include implementation narration.
